# 핫챠 클레이 에셋 v2

기본 제공 이미지 생성 도구로 8종을 개별 생성했다. 매트 클레이 재질을 유지하고 에셋마다 민트·코랄·살구·하늘색·노란색 포인트를 적용했다. PNG 원본이며 기존 v1은 보존했다. 앱 에셋 카탈로그 Resources/Assets.xcassets/Clay에 HotChaClayBus, HotChaClayHouse, HotChaClayOffice, HotChaClaySchool, HotChaClayMagnifier, HotChaClayBell, HotChaClayBusStop, HotChaClayStar 이름으로 등록했다. 앱 화면은 변경하지 않았다.

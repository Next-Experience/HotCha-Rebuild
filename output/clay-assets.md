# HotCha 매트 클레이 PNG 에셋

버스·집·회사·학교·돋보기·알림 벨·정류장·즐겨찾기 별 8종. 기본 제공 이미지 생성 도구로 각각 생성했다. 이미지 생성 스킬의 개별 생성·투명 배경·프로젝트 저장 절차를 적용했다.

앱 에셋 카탈로그에는 컬러 포인트를 적용한 v2 PNG를 등록했다. 버스는 보라·민트·크림, 집은 코랄 지붕, 회사는 하늘색 창문, 학교는 살구색 지붕, 돋보기는 민트 렌즈, 종은 노란 몸체, 정류장은 민트 지붕, 별은 노란 테두리를 사용한다. 매트 클레이 재질, 둥근 형태, 부드러운 좌측 상단 조명을 유지한다.

화면에는 아직 배치하지 않았다. [v2 원본과 생성 프롬프트](assets/clay-v2/README.md)를 보관했으며, 기존 보라색 버전은 assets/clay-v1/에 보관했다. 아래 리소스 이름은 새 PNG에 그대로 사용할 수 있다.

### Bus

Use case: stylized-concept. Asset type: standalone transparent PNG illustration for HotCha, a Korean iOS bus arrival alarm app. Create ONE centered 3D matte-clay city bus icon on genuine transparent background. Square 1024x1024 canvas, generous transparent padding, object occupies about 75% of canvas. Friendly refined rounded miniature proportions, front and right side visible, front facing viewer-left, mildly elevated three-quarter orthographic camera. Rich violet #6558D8 body, lavender #B5A9ED secondary parts, ivory details, dark desaturated purple windows, charcoal rounded wheels, two tiny warm cream headlights. Broad clean shapes recognizable at 48px. Matte smooth clay with subtle soft edge highlights, soft studio key light from upper-left, minimal tight ambient contact shadow only, no opaque floor. No text, route number, logo, face, scenery, decorative base, gradient backdrop, border, tile or watermark. It must be one bus, not an icon sheet. Premium friendly app asset, avoid shiny plastic and metallic surfaces.
